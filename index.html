🗑️ Delete page
Chọn một hoặc nhiều trang muốn xóa khỏi tài liệu. Hành động này không thể hoàn tác bằng Undo.
✂️ Extract Pages
Chọn một hoặc nhiều trang muốn tách ra. Các trang đã chọn sẽ được lưu thành 1 file PDF MỚI (giữ nguyên mọi chỉnh sửa đã thực hiện) — tài liệu đang mở trên màn hình không bị thay đổi gì.
📝 Export Word Document
Chọn các trang muốn xuất sang Word (mặc định: tất cả các trang). Nội dung xuất ra sẽ giữ đúng vị trí/bố cục như trong bản gốc (kể cả bảng biểu), bao gồm cả những chỉnh sửa bạn đã thực hiện.
📥 Insert pages
🧩 Combine Files
Thêm các file PDF muốn gộp lại thành một file duy nhất. Kéo-thả (hoặc dùng nút ▲▼) để sắp xếp lại thứ tự trước khi gộp.
Chưa có file nào. Bấm "Thêm file PDF..." để bắt đầu.
🗜️ Compress PDF
Giảm dung lượng file PDF (giữ nguyên mọi chỉnh sửa hiện tại). Mỗi trang sẽ được dựng lại thành ảnh nén — do đó chữ trong file đã nén sẽ không còn bôi đen/copy được như file gốc. Nếu cần giữ chữ chọn được, hãy dùng "Save PDF" thay vì nén.
